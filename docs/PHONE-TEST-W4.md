# W4 — IWACU RWANDA 2 phone test (Android / Chrome)

Iyi ni test ikorerwa kuri telefone ukoresheje taps gusa. Ntukeneye guhindura code
cyangwa kohereza password, API key, cyangwa coordinates zawe.

1. Fungura IWACU RWANDA 2 muri Chrome. Reba niba page irangiye gufunguka.
2. Muri Android Settings, fungura Location. Muri Chrome Site settings, emera Location kuri uru rubuga.
3. Subira kuri IWACU, ukande Menya aho ndi. Tangira kubara amasegonda.
4. Reba igihe igisubizo cya mbere kigaragaye. Intego ni amasegonda 3 cyangwa munsi yayo uhereye ku kimenyetso cya mbere cyabonetse.
5. Reka page ikomeze ifunguye amasegonda 30. Reba niba GPS nziza isimbura prior cyangwa network estimate, nta gihe screen iba blank.
6. Subiramo uri mu nzu, kure y'idirishya. Andika niba igisubizo cya mbere cyabonetse n'uko cyanditswe (GPS, network, prior).
7. Fungura ikarita, ukande ahantu, hanyuma ukande Koresha aha hantu. Reba niba igisubizo kigaragaza ahantu hamwe n'ID ikoreshwa na /api/locate.
8. Umaze gufungura picker uri online, fungura Airplane mode. Ongera ufungure picker urebe niba response yari yarabitswe igaruka offline.
9. Kuri Rubavu hafi y'inkengero z'Ikiyaga cya Kivu, gerageza ahantu ho ku mazi. Temporary border_zone igomba kugaragaza Akarere cyangwa urwego rwo hejuru; ntigomba kwemeza umudugudu.
10. Kanda Koporora raporo. Paste text muri review message. Reba ko itarimo amazina y'ibanga, password, cyangwa exact coordinates.

Kuri buri ntambwe andika: PASS/FAIL, amasegonda igisubizo cya mbere cyafashe,
urwego rwerekanywe, flags, niba igisubizo cyavuguruwe, n'ubutumwa bw'ikosa.
Ntuhitemo ahandi ngo uhishe ikibazo; amakosa ni evidence ikenewe.
